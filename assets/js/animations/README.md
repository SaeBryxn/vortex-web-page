# VORTEX Animation System

This folder contains the premium motion layer for the VORTEX corporate website.

## Stack

- Lenis: smooth scrolling.
- GSAP: advanced animation engine.
- ScrollTrigger: scroll-based animation, pinning, scrub and sequencing.

## Files

- `smooth-scroll.js`: initializes Lenis.
- `gsap-config.js`: registers ScrollTrigger and synchronizes it with Lenis.
- `reveal.js`: lightweight reveal animations.
- `parallax.js`: simple parallax system.
- `hero-motion.js`: premium hero timeline.
- `scroll-story.js`: pinned storytelling sections.

## Rules

- Motion must be subtle, technical and premium.
- Avoid excessive movement or decorative animation.
- Always respect `prefers-reduced-motion`.
- Pinning should be limited on mobile.
